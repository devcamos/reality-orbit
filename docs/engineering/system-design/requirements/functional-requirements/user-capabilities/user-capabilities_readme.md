# User Capabilities

**Parent:** [Functional Requirements](../functional-requirements_readme.md)  
**Level:** L3  
**Status:** Learning example

## Purpose

User-capability artefacts describe an action a user can complete and the system outcome that follows. They should be small enough to test end to end.

## Child artefacts

| L4 artefact | What it teaches |
| --- | --- |
| [Explore the selected ontology node](explore-selected-ontology-node.md) | A compact Reality Orbit functional requirement, acceptance scenario, and sequence diagram |

## Check before adding an L4

A leaf document should name one user goal, state the business rule and error behaviour, and point to evidence. If it needs several unrelated user goals, split it into separate L4 artefacts.
